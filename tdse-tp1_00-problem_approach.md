1. Intelligent Parking Management System:

Describe un sistema automático de estacionamientos inteligente, compuesto por los módulos

▻ Parking System Server
▻ Entry Machine 
▻ Exit Machine
▻ Toll Computer and/or Automatic Pay Station

El sistema en general permite al conductor estacionar el vehículo en una playa de estacionamientos, donde al terminar de usar el servicio debe abonar 
el monto correspondiente al tiempo de uso, presentando el ticket en Automatic Pay Station. Luego tiene un tiempo para retirarse, mostrando el ticket
abonado en Exit Machine.

2. Automated Parking System (Entry / Exit)

Un sensor de campos electromagnéticos detecta la llegada de un vehículo a la entrada, la máquina le expende un ticket que registra el tiempo de 
llegada con su identificador. Luego la barrera se activa por medio de detección por cámara.
A la salida el sensor de campos detecta la llegada de un vehículo, entonces si el usuario ingresa el ticket previamente abonado se abre la barrera de
salida, que luego se cierra cuando otro sensor de campos detecta la salida del vehículo.
